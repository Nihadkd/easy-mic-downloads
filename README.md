# Easy Mic — Android test downloads

This repository contains installation downloads only. The application source stays private.

Easy Mic sends the phone's microphone to an external Bluetooth speaker. This is a test candidate, not a fully verified production release. Physical Bluetooth, latency and long-duration tests remain unverified.

Android 8.0 or newer is required. The APK uses the existing local Android test signing key. Android may ask you to confirm download and installation. Start with low speaker volume.

Use the APK under Releases or the supplied direct-download QR. SHA256SUMS.txt identifies the exact binary. No app source or signing keys are published here.
